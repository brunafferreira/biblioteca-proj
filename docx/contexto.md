# CONTEXTO.md

## 1. Visão Geral
Este é um sistema de gestão de biblioteca desenvolvido com Next.js e TypeScript

## 2. Objetivo
Permitir o cadastro de alunos e o gerenciamento de livros

## 3. Tecnologias
Next.js 15 (App Router)
TypeScript
Tailwind css
React (componentes)
LocalStorage (para dados locais)

## 4. Estrutura de Pastas
- app/ páginas e rotas da aplicação
- components/ componentes reutilizáveis
- lib/ funções e utilitários
- public/ arquivos estáticos (imagens, icones)
